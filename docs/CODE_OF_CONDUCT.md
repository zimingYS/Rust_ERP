# 贡献者行为准则

## 我们的承诺

为营造开放、友善、无骚扰的协作环境，无论年龄、体型、残障、族群、性别认同与表达、经验水平、教育程度、社会经济地位、国籍、外貌、种族、宗教信仰或性取向，所有参与者都应在项目中获得尊重。

## 我们的标准

**鼓励的行为**

- 使用友善、包容的语言，尊重不同观点与经验
- 给出建设性的技术反馈，并优雅接受他人批评
- 以项目与社区的整体利益为先
- 对他人保持同理心，尤其在指出错误时

**不可接受的行为**

- 带有性暗示的言语或图像、不受欢迎的性关注或搭讪
- 引战、侮辱 / 贬损性评论、人身攻击或政治性攻击
- 公开或私下骚扰、跟踪、未经同意发布他人隐私信息
- 未经授权发布他人私人信息（如真实地址、邮箱、口令）
- 其他在专业环境中合理认定为不当的行为

## 适用范围

本准则适用于所有项目空间（Issue、Pull Request、Discussion、Commit、Review），以及个人在公开场合代表本项目时的行为。代表项目包括在官方账号发帖、在活动中作为指定代表出席等情形。

## 执行

遇到不可接受的行为，请通过 GitHub 的私有报告渠道（Security Advisories）或直接在仓库中私信维护者反馈。所有投诉都会被及时、公正地审阅，举报人身份将被保密。

维护者有责任澄清并执行行为标准，可采取以下措施，视情节轻重而定：

1. **纠正**：私下书面警告，说明违规性质并要求停止 / 道歉
2. **警告**：警告并明确后续违规的后果，一定期限内限制与相关人员的互动
3. **临时封禁**：暂时禁止与项目社区进行任何互动
4. **永久封禁**：永久禁止在社区内任何形式的公开互动

维护者若未善意执行本准则，可能面临项目治理层面的临时或永久处分。

## 归属

本准则参考 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 与 [Chinese translation](https://www.contributor-covenant.org/zh-cn/version/2/1/code_of_conduct/) 的结构与原则编写，并结合本项目实际做了精简。

常见问题见 [Contributor Covenant FAQ](https://www.contributor-covenant.org/faq)。
